# Endpoint Analyzer

A full-stack web application for analyzing JSON-formatted API logs and visualizing performance metrics.

The application includes an success rate, status code distribution, and latency metrics (Median, P95, and Max).


## Live Application

- **Frontend (Vercel):** [Endpoint Analyzer Web](https://endpoint-analyzer.vercel.app)
- **Backend API (Railway):** Node.js & Express REST API handling log analysis.


## Features

- **Endpoint Success Rate**  
  Highlights the least successful endpoints based on error and failure rates.
- **Latency**  
  Median, P95, and Maximum latency metrics for specific endpoints.
- **Status Code Distribution**  
  Chart that show the distribution of 2xx, 3xx, 4xx, and 5xx responses.
